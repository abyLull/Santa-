# 🎅 Тайный Санта команды E-license

Анонимная жеребьёвка с пожеланиями: каждый знает, кому дарит, но не знает, кто дарит ему.

## Как играть
1. Организатор создаёт игру: название, бюджет, дата обмена. Сразу после создания он получает ссылку для чата и резервный код.
2. Участники открывают ссылку на телефоне и зажимают кнопку, чтобы подать заявку: имя, PIN и пожелание (можно со ссылкой на Kaspi, Ozon, WB).
3. Организатор при необходимости добавляет исключения (кто не дарит друг другу) и распределяет пары.
4. Каждый зажимает кнопку, ставит печать «ВЫДАНО» и видит, кому дарит, вместе с актуальным пожеланием.
5. Санта и получатель могут анонимно переписываться, Санта отмечает «подарок готов».
6. После праздника организатор раскрывает цепочку, и все видят финал с анимацией.

## Возможности
- Пары хранятся только на сервере, API организатора их не отдаёт. Переписку организатор тоже не видит.
- Одна общая цепочка без взаимных пар. С исключениями: поиск цепочки с возвратом, если не получается — любая допустимая перестановка.
- Сброс PIN участника на 0000 с обязательной сменой при входе.
- Резервный код организатора для восстановления доступа.
- QR-код (`/api/games/<id>/qr.svg`) и плакат для печати (`/g/<id>/poster`).
- Обратный отсчёт до даты обмена.
- Ночная тема по настройкам телефона, казахский язык (переключатель ҚАЗ / РУС).

## Файлы
`server.js`, `store.js`, `qr.js`, `package.json` и `index.html` (в корне или в `public/`).

## Запуск
```bash
npm install
DATABASE_URL=postgresql://... npm start   # без DATABASE_URL данные хранятся в памяти
```

## Деплой (Render)
- Runtime: Node, Build: `npm install`, Start: `node server.js`
- `DATABASE_URL` — строка подключения Postgres (например, Neon). Таблица создаётся автоматически.
- Чтобы бесплатный сервис не засыпал днём, он сам пингует себя с 9:00 до 21:00 по Астане (использует `RENDER_EXTERNAL_URL`, его Render задаёт сам).
  `KEEP_AWAKE=0` — выключить, `KEEP_AWAKE_HOURS=8-22` — другие часы.
