# 🎅 Тайный Санта

Анонимная жеребьёвка с пожеланиями: каждый знает, кому дарит, но не знает, кто дарит ему.

## Как играть
1. Организатор открывает сайт и создаёт игру, затем отправляет ссылку в общий чат.
2. Участники открывают ссылку на телефоне, вводят имя, PIN из 4 цифр и пожелание.
3. Организатор нажимает «Распределить». Получается одна общая цепочка: никто не дарит сам себе, взаимных пар нет.
4. Каждый видит, кому дарит, и актуальное пожелание этого человека. Своё пожелание можно менять в любой момент.

Пары хранятся только на сервере. API организатора их не отдаёт.

## Запуск
```bash
npm install
DATABASE_URL=postgresql://... npm start   # без DATABASE_URL данные хранятся в памяти
```

## Деплой (Render)
- Runtime: Node, Build: `npm install`, Start: `node server.js`
- Переменная окружения `DATABASE_URL` — строка подключения Postgres (например, Neon). Таблица создаётся автоматически.
